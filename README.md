# TrackTime
TrackTime is a app designed to make following motorsports series easier.

Following different motorsports series is an annoying task that usually requires adding events to your calendar and then creating alarms and reminders specifically for those events to make sure you don't miss out, especially when they aren't in your time zone. TrackTime solves this by automatically creating reminders and alarms for you based on the motorsport series you follow so you can get back to enjoying the sport you love.

# Goals
Currently the app is in very early pre-alpha and I do not have very well defined goals however if you have an idea you think would make TrackTime better feel free to reach out on Discord or by creating an issue with specific implementation details.    

0. Working user signup and login: Currently Supabase is being used as I don't want to roll my own auth this may change in future versions.
1. Make it a PWA: I think PWA's are in a state where the core features of this app should be possible without needing platform specific code.
2. User dashboard for following specific motorsport series
3. Notifications & Alarms using service workers for upcoming events and race starts
4. More to come!
